Guía de Integración para Microservicios Productores

Especificación técnica de Exchange, Routing Keys, Payloads JSON y Claims JWT que cada microservicio debe emitir hacia ms-estadisticas.

Exchange: styleradar.exchange (topic, durable) Broker: 5672 / 5671 TLS
1. Broker RabbitMQ
Topic Exchange Durable

Publicar siempre al exchange styleradar.exchange con content_type: application/json. ms-estadisticas ya declara sus colas y bindings.

2. Idempotencia
eventId / eventoId único

Todo mensaje debe incluir un ID único en eventId (o eventoId) y fecha ISO-8601 en occurredAt (o fechaCreacion).

3. Tolerancia de Campos
Alias Español / Inglés

El consumidor acepta storeId/tiendaId, foundationId/fundacionId, amount/monto/cantidad e ignora propiedades extra.

4. Seguridad JWT (auth:8100)
Secreto y Claims compartidos

Compartir JWT_SECRET con ms-auth:8100 e incluir role + storeId/nit o foundationId en el JWT.
